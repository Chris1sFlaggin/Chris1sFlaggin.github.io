Trova i follower bot di un account che gestisci, dà a ognuno un punteggio da 0 a 100 e ti fa ripulire in blocco. Gira interamente nella console del browser: niente da installare, nessun dato esce dal tuo PC.

Nessuna installazione Dati solo in locale MIT Fork di InstagramUnfollowers

⚠️ Usalo solo su account che gestisci con autorizzazione. Rimuovere follower e cancellare commenti sono azioni irreversibili: la responsabilità dell'uso è tua.

Come funziona

Quattro passaggi, zero installazioni

  1. Scarica la lista follower e assegna un bot-score 0–100 dai dati base: username, nome, foto, profilo privato. Verificati e mutual (chi l'account segue indietro) sono sempre esclusi.
  2. Deep-scan opzionale sui soli candidati sospetti: rapporto follower/following, numero di post, account creato di recente, bio. Scarica il profilo solo per chi è già stato segnalato, così le richieste restano poche.
  3. Revisione: la lista è ordinata per punteggio, sposti la soglia, controlli e metti in whitelist i falsi positivi. La whitelist resta salvata tra una sessione e l'altra.
  4. Rimozione in blocco, con pause tra un'azione e l'altra per non farsi bloccare. 4 secondi tra le azioni e una pausa più lunga ogni pochi rimossi.

Istruzioni

Come si usa

  1. Premi Copia il codice qui sopra, sul tool che ti serve.
  2. Apri instagram.com nel browser ed entra con l'account da analizzare. Le azioni funzionano solo se sei loggato come quell'account.
  3. Apri la console per sviluppatori. Windows e Linux: Ctrl + Shift + J — macOS: ⌘ + ⌥ + I
  4. Incolla il codice e premi Invio. Se il browser chiede di scrivere allow pasting prima di poter incollare, fallo: è una protezione di Chrome, va scritto una volta sola.
  5. Compare l'interfaccia sopra Instagram: premi RUN e aspetta la scansione. Più follower ha l'account, più tempo serve. Non chiudere la scheda.
Prima di iniziare

Verifica che le API rispondano

Instagram cambia spesso le proprie API interne, e quando succede il tool smette di funzionare finché non viene aggiornato. Questo controllo dura due secondi e ti dice subito se puoi procedere. Incollalo in console su instagram.com loggato:

(async () => {
  const ds = document.cookie.match(/ds_user_id=(\d+)/)?.[1];
  const h = { headers: { 'x-ig-app-id': '936619743392459' }, credentials: 'include' };
  const f = await fetch(`https://www.instagram.com/api/v1/friendships/${ds}/followers/?count=5`, h)
    .then(r => r.json());
  console.log('FOLLOWERS →', f.users?.length, 'utenti; next', f.next_max_id);
})();

Se vedi un elenco di utenti, sei a posto. Se la risposta è vuota o dà errore, gli endpoint sono cambiati: aspetta un aggiornamento del tool.

Da sapere

Note e limiti

I dati restano tuoi

Tutto avviene nel browser, sulla sessione già aperta. Non c'è nessun server intermedio e nessuna lista viene caricata da nessuna parte. La whitelist sta nel localStorage.

Il punteggio è un indizio

Il bot-score è una stima basata su segnali pubblici, non una sentenza. Controlla sempre la lista prima di rimuovere: gli account nuovi o senza foto non sono per forza bot.

Vai piano

Le rimozioni sono intervallate da pause proprio per non farsi limitare. Non ridurre i tempi e non lanciare più tool insieme sullo stesso account.

Può rompersi

Si appoggia alle API interne di Instagram, che cambiano senza preavviso. Se qualcosa non va, rifai il controllo qui sopra prima di ogni altra cosa.
